# 제작·검증 기록: 코디세이 입학연수 설문조사 페이지

## 두 AI 비교
- AI A (서비스·모델 이름): Google AI Studio · Gemini Flash 3
- AI B (서비스·모델 이름): Claude.ai · Claude Sonnet 4.6
- 동일한 기획서와 함께 전달한 요청: 하나의 html 파일로 만들어줘

| 테스트 내용 | AI A (Gemini Flash 3) | AI B (Claude Sonnet 4.6) |
| --- | --- | --- |
| 출력 완성도 | 코드가 잘리지 않고 한 번에 완성 출력 | 첫 시도에서 코드가 잘려 HTML 오류 발생, 2회 시도 필요 |
| 기능 구현 수준 | 요구 기능을 빠짐없이 구현, 완성도 높음 | 2회 시도 후 완성했으나 일부 기능 완성도가 낮음 |
| 디자인·UI | 깔끔한 카드형 레이아웃, 시각적으로 완성도 높음 | 기본적인 스타일, 단순한 구성 |

- 선택한 결과물과 근거:
  - **Gemini Flash 3 결과물 선택**
  - Gemini: 생각보다 더 기능을 완성도 높게 잘 만들어서 놀람
  - Claude: 첫 번째 결과물에서 출력값이 잘려 HTML 오류 발생. 2번째 시도에서 완성했으나 결과물의 기능 완성도가 떨어짐

## 수정 기록

### 수정 기록 1
- **발견한 문제:** Claude 첫 번째 출력에서 HTML 코드가 중간에 잘려 브라우저에서 페이지가 정상 표시되지 않음
- **AI에게 전달한 요청:** "짧게 만들어줘"
- **수정 후 테스트 결과:** 코드가 잘리지 않고 완성 출력됨, 브라우저에서 정상 표시 확인
- **수정 이유:** 코드 길이를 줄여 출력이 잘리는 문제를 방지하기 위해

### 수정 기록 2
- **발견한 문제:** 설문 항목이 5개 기획 대비 3개(Q1·Q2·Q3)만 구현되어 Q4·Q5 누락
- **AI에게 전달한 요청:**
- **수정 후 테스트 결과:** Gemini 결과물에서 5개 항목 모두 정상 확인
- **수정 이유:** 기획서 요구사항(항목 5개)을 충족하는 결과물로 교체

### 수정 기록 3
- **발견한 문제:** Claude 결과물에서 익명 제출과 일반 제출의 동작 차이가 화면에 표시되지 않아 사용자가 구분하기 어려움
- **AI에게 전달한 요청:**
- **수정 후 테스트 결과:** Gemini 결과물에서 두 버튼 모두 완료 메시지로 정상 전환 확인
- **수정 이유:** 익명 제출 기능이 명확하게 동작하는 결과물이 필요했기 때문

## 사용자 테스트
- **테스트 참여자와 요청한 작업:** 코디세이 입학연수 과정생 1명에게 설문 페이지를 직접 열어 처음부터 끝까지 작성·제출해 달라고 요청
- **사용자의 행동과 질문:** Q1 체크박스를 선택하지 않고 바로 제출 버튼을 눌렀고, 오류 메시지를 보고 "이게 필수예요?" 라고 질문함
- **받은 피드백:** "필수 표시(\*)가 눈에 잘 안 띄어요. 설명 문구가 있으면 좋겠어요"
- **반영 내용과 결과:** 상단 안내 문구에 "* 표시 항목은 필수입니다" 문장을 추가하여 필수 여부를 명확히 안내함
