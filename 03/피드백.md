# 📋 피드백 양식 정리

## 잘된 점
- 데이터와 UI가 분리되어 있어서 코드 수정이 간단했다
- 한국어/일본어 전환이 부드럽게 작동한다
- 영화를 Tier 버튼으로 쉽게 이동할 수 있다
- 모바일에서도 레이아웃이 잘 정렬된다

---

## 고치면 좋을 점

### 1️⃣ 이미지 깨짐
- **본 것:** 영화 포스터 이미지를 클릭해서 보려고 했더니 깨진 이미지(X 표시)가 나왔다
- **기준:** 기획서에는 "각 영화의 포스터 이미지가 표시되어야 함"이라고 명시되어 있다
- **제안:** `via.placeholder.com` 대신 `placehold.co`나 실제 이미지 URL로 교체하면 좋겠다

### 2️⃣ 드래그 기능 미작동
- **본 것:** 영화 카드를 드래그해서 다른 Tier로 옮기려고 했더니 아무것도 일어나지 않았다
- **기준:** 기획서에는 "드래그로 영화를 Tier 간 이동 가능"이라고 되어 있다
- **제안:** `dragstart`, `dragover`, `drop` 이벤트 핸들러를 추가해서 드래그 기능을 완성하면 좋겠다

### 3️⃣ Tier 제목이 언어 전환 안 됨
- **본 것:** 일본어로 보기 버튼을 눌렀더니 "Tier 1, Tier 2, Tier 3" 제목이 그대로 남아있다
- **기준:** 다른 텍스트들(제목, 버튼)은 모두 일본어로 바뀌는데 Tier 제목만 안 바뀐다
- **제안:** `render()` 함수에서 `.tier-title` 요소도 `uiText` 데이터로 업데이트하면 좋겠다
