# 미션 3 기록

| 받은 의견 | 직접 해 본 결과 | 반영 / 보류 / 되묻기 | 이유 (되묻기라면 물을 질문) |
|---|---|---|---|
| 이미지 깨짐 (`via.placeholder.com` 서비스 종료) | 실제로 포스터 이미지가 X 표시로 깨져 있었다 | **반영** | 기획서 요구사항(포스터 표시)을 충족하지 못하고 있음 |
| 드래그 기능 미작동 (이벤트 핸들러 없음) | 카드를 드래그해도 움직이지 않았다 | **반영** | 기획서에 명시된 "드래그로 Tier 이동" 기능이 완전히 구현되지 않음 |
| Tier 제목 미번역 (`uiText` 미사용) | 일본어 전환 시 "Tier 1, 2, 3"만 남아있었다 | **반영** | 다른 텍스트는 모두 번역되는데 일관성이 깨짐 |

## 아무도 말하지 않았는데 내가 찾은 것:

- **하드코딩된 Tier 수** → `for (let tier = 1; tier <= 3; tier++)` 에서 3이 고정되어 있어서, Tier를 4개 이상으로 늘리려면 HTML과 JS를 모두 수정해야 함
- **`innerText` vs `textContent`** → 성능과 보안상 `textContent`가 더 안전한데 현재 `innerText` 사용 중
- **이모지 호환성** → 🇰🇷 이모지가 일부 환경에서 깨질 수 있으니 alt 텍스트 추가 권장
