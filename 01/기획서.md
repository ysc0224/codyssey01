# 📋 K-콘텐츠 티어리스트 기획서

## 1. 누가 쓰나 (사용자)
*   한국 영상 콘텐츠(드라마, 영화 등)에 관심이 있는 **일본인 사용자**

## 2. 무엇을 하려고 (목적)
*   다양한 한국 영상 콘텐츠를 확인하고, 자신의 선호도에 따라 **티어별(1~3단계)로 분류**하여 한눈에 확인하기 위함

## 3. 화면과 동작
*   **화면 구성**:
    *   상단: 제목 및 **한국어/일본어 전환 버튼**
    *   중앙: 3개의 티어 구역 (Tier 1, Tier 2, Tier 3)
    *   카드: 콘텐츠 포스터, 제목, 플랫폼, 가격 정보, **티어 이동 버튼(1, 2, 3)**
*   **주요 동작**:
    *   **언어 전환**: 버튼 클릭 시 제목, 설명, 콘텐츠 상세 정보가 한국어 또는 일본어로 즉시 변경됨
    *   **티어 이동**: 각 카드에 붙은 숫자 버튼을 누르면 해당되는 티어 구역으로 카드가 즉시 이동함

## 4. 필요한 자료
*   **콘텐츠 데이터**: 각 영상의 ID, 한국어/일본어 제목, 포스터 이미지 URL, 스트리밍 플랫폼 정보, 언어별 가격 정보
*   **UI 텍스트**: 한국어와 일본어로 번역된 페이지 내 고정 문구(제목, 설명 등)
*   **이미지 자산**: 각 콘텐츠의 포스터 이미지 (현재는 샘플 이미지 사용 중)

## 5. 완성 기준
*   단일 HTML 파일 내에서 모든 기능(이동, 언어 전환)이 오류 없이 작동해야 함
*   한국어와 일본어 상태에서 데이터가 정확하게 매칭되어 표시되어야 함
*   사용자가 버튼을 눌렀을 때 별도의 새로고침 없이 화면이 갱신되어야 함

---

### ⚠️ 미정 사항 (확인 필요)
기획을 완성하기 위해 아래 항목들은 추가적인 결정이 필요합니다.

1.  **최종 콘텐츠 리스트**: 현재 샘플로 들어간 3개 작품 외에 실제로 어떤 작품들을 기본으로 노출할지 확정이 필요합니다.
2.  **데이터 저장 방식**: 현재는 페이지를 새로고침하면 배치가 초기화됩니다. 사용자가 분류한 티어를 브라우저에 저장(LocalStorage 등)할지 여부가 정해지지 않았습니다.
3.  **추가 티어 개수**: 현재는 3단계(Tier 1~3)로 구성되어 있으나, 티어 단계를 늘리거나 줄일지 확인이 필요합니다.
4.  **배포 방식**: 단순히 로컬 파일로 사용할지, 웹사이트 주소(URL)를 통해 접속 가능하게 배포할지 정해지지 않았습니다.
